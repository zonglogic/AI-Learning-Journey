## 学习记录

### Day 01 — Python 数据类型

- 学习 `Decimal` 的基本使用
- 对比普通浮点数与十进制定点数的计算结果
- 理解浮点数精度问题

示例：

```python
from decimal import Decimal

num1 = Decimal("0.1")
num2 = Decimal("0.2")
print(num1 + num2)  # 0.3
```
